# Расчёт DAU на платформе Симулейтив

Этот репозиторий содержит SQL-запрос для расчёта и анализа динамики метрики DAU на платформе Симулейтив. Проект является выпускной работой на курсе по SQL от Симулейтив. 
**Данные**. Доступ к базе данных Симулейтив был предоставлен компанией Симулейтив.

### Задача

Необходимо рассчитать и проанализировать динамику продуктовой метрики активности пользователей на платформе Симулейтив (Daily Active Users, DAU).

Анализ DAU позволяет выявить тренды пользовательской активности, определить пики и спады, а также лучше понять поведение аудитории. В дальнейшем результаты исследования могут быть использованы для принятия более обоснованных решений по улучшению пользовательского опыта, увеличению вовлеченности и оптимизации маркетинговых стратегий.

### Решение

**Технический стек**: SQL, DBeaver, PostgreSQL
