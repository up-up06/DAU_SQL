# Расчёт DAU на платформе Симулейтив

Этот репозиторий содержит SQL-запрос для расчёта и анализа динамики метрики DAU на платформе Симулейтив. Проект является выпускной работой на курсе по SQL от Симулейтив. 

### Задача

Необходимо рассчитать и проанализировать динамику продуктовой метрики активности пользователей на платформе Симулейтив (Daily Active Users, DAU) в период с 01.01.2022 и последующие 150 дней.

Анализ DAU позволяет выявить тренды пользовательской активности, определить пики и спады, а также лучше понять поведение аудитории. В дальнейшем результаты исследования могут быть использованы для принятия более обоснованных решений по улучшению пользовательского опыта, увеличению вовлеченности и оптимизации маркетинговых стратегий.

### Данные 

**Источник**. Доступ к базе данных Симулейтив был предоставлен компанией Симулейтив.
**Описание**. В рамках проекта использовались данные из таблицы `userentry`, содержащей информацию о входах пользователей на платформу.

### Технический стек

SQL, DBeaver, PostgreSQL

### Решение

SQL-скрипт сорержится в файле `Script_dau.sql`

**Описание**:  
Запрос рассчитывает ежедневное количество активных пользователей (DAU) за 150 дней, начиная с 01.01.2022, и вычисляет текущую просадку метрики относительно исторического максимума на каждый день периода.

**Ключевые технические особенности запроса**:
* Обработка нулевой активности: Используется генерация временного ряда (`generate_series`) и `RIGHT JOIN` для сохранения в отчете дней с нулевым счетчиком пользователей.
* Расчет скользящего максимума: Применена оконная функция `MAX() OVER` с сортировкой по времени для накопления максимального значения DAU.
* Анализ отклонений: В финальной выборке рассчитывается разница (diff_dau) между текущим DAU и пиковым значением для поиска аномалий и спадов в активности.
