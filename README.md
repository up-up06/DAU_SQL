# Расчёт DAU на платформе Симулейтив

Этот репозиторий содержит SQL-запрос для расчёта и анализа динамики метрики DAU на платформе Симулейтив.  
Проект является выпускной работой на курсе по SQL от Симулейтив. 

## Задача

Необходимо рассчитать и проанализировать динамику продуктовой метрики активности пользователей на платформе Симулейтив (Daily Active Users, DAU).

Анализ DAU позволяет выявить тренды пользовательской активности, определить пики и спады, а также лучше понять поведение аудитории. В дальнейшем результаты исследования могут быть использованы для принятия более обоснованных решений по улучшению пользовательского опыта, увеличению вовлеченности и оптимизации маркетинговых стратегий.

### Решение

SQL-скрипт сорержится в файле `Script_dau.sql`.

**Технический стек:** SQL, DBeaver, PostgreSQL.

**Описание**: Запрос рассчитывает ежедневное количество активных пользователей (DAU) за 150 дней, начиная с 01.01.2022, и вычисляет текущую просадку метрики относительно исторического максимума на каждый день периода.

**Ключевые технические особенности запроса**:
* Модульная архитектура через CTE: Аналитическая логика декомпозирована на изолированные обобщенные табличные выражения.
* Обработка нулевой активности: Используется генерация временного ряда `generate_series()` и `RIGHT JOIN` в связке с функцией `COALESCE()` для сохранения в отчете дней с нулевым счетчиком пользователей.
* Расчет скользящего максимума: Применена оконная функция `MAX() OVER` с сортировкой по времени для накопления максимального значения DAU.
* Анализ отклонений: В финальной выборке рассчитывается разница между текущим DAU и пиковым значением для поиска аномалий и спадов в активности.

## Как использовать

1. Клонируйте репозиторий
   ```bash
    git clone https://github.com/up-up06/DAU_SQL.git
    cd dau_sql   
   ```
2. Настройте подключение к базе данных Симулейтив через DBeaver.  
   Подровнее почитать как установить подключение можно [здесь](https://app.simulative.ru/course/50/2050).
3. В среде разработки DBeaver откройте файл `Script_dau.sql` и выполните SQL-запрос.
